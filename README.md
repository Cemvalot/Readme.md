## 🚀 Featured Projects

Here are the projects I've built and maintained:

### [Odysseus](https://github.com/Cemvalot/Odysseus)
**Personal AI OS** — A local-first, single-user AI operating system combining conversation, semantic memory (384-dim), bounded agents, typed workflows with human approvals, schedules, a tiered Context Hub, and controlled personal integrations (email, calendar, GitHub, browser, WhatsApp). Features FastAPI + PostgreSQL/pgvector + Redis + Celery backend, bearer-protected management APIs, mock-first adapters, and free browser speech recognition/synthesis.

### [Metronome](https://github.com/Cemvalot/Metronome)
**City-Transformative Intelligence Dashboard** — GeoServer proxy, WFS integration for feature queries, map tiling for visual exploration, clustering analysis for pattern detection, and a real-time web dashboard built with JavaScript and Flask.

🌐 **Live:** [portal.metronomeproject.eu](https://portal.metronomeproject.eu)

### [it-operations-hub](https://github.com/Cemvalot/it-operations-hub)
**IT Operations Management Dashboard** — Track network devices, monitor credential renewals via KeePassXC integration, manage SharePoint/Microsoft 365 connections, track renewal alerts, and use checklist templates. Multi-language UI (Greek/English), SQLite backend, Node.js + Express server, email integration, file upload, and admin interface.

### [DESKTOP-RIG](https://github.com/Cemvalot/DESKTOP-RIG)
**PC/Tablet Remote Control Kiosk** — Remote control of PC/tablet displays with virtual keyboard, trackpad, and display management over LAN. Auth + WebSocket + LAN security model. JavaScript + Express.

### [smaca](https://github.com/Cemvalot/smaca)
**Smart Building Intelligence Platform** — Full-stack IoT/sensor monitoring dashboard built with Laravel (PHP). Real-time data, alerts, device management, air quality/occupancy/energy monitoring, predictive AI insights, and a focused toolkit for real-time operational visibility. Targeted at universities, public buildings, and municipal facilities.

### [attica-game](https://github.com/Cemvalot/attica-game)
**SDG Educational Game** — Interactive React game about Sustainable Development Goals with multiple levels, animations, and responsive design.

### [dei_extractor](https://github.com/Cemvalot/dei_extractor)
**DEI Data Extraction Tool** — Python package for extracting and processing DEI-related data with CLI interface, core extraction modules, utilities, and comprehensive tests.

### [graphqlrender](https://github.com/Cemvalot/graphqlrender)
**GraphQL Rendering Library** — Python library for rendering GraphQL queries with a pluggable render engine, Express-based server, tests, and MIT license.

### [innovateeast-website](https://github.com/Cemvalot/innovateeast-website)
**Innovate East Conference Website** — Vite + React + Tailwind CSS + TypeScript website deployed to Netlify with CSP headers, analytics, and full conference content.

### [retro-dev-odyssey](https://github.com/Cemvalot/retro-dev-odyssey)
**Modern React Dashboard** — Built with Vite, TypeScript, shadcn/ui, and Tailwind CSS. Clean dashboard with animations, dark mode, and responsive design.

### [clonernews](https://github.com/Cemvalot/clonernews)
**Hacker News UI Clone** — Vanilla JS application using the Firebase HN API with infinite scroll, nested comment threads, modal post viewer, live updates sidebar, keyboard support, and rate limiting.

### [mparmperis-development](https://github.com/Cemvalot/mparmperis-development)
**Portfolio & Projects Site** — Development portfolio built with Vite + React + Tailwind CSS + TypeScript, Base44 integration. Barber service platform with filters, booking calendar, user notifications, and authentication flow.

### [e-shop](https://github.com/Cemvalot/e-shop)
**E-Commerce Platform** — Full Ruby on Rails application with Devise authentication, products CRUD, image uploaders, mailers, ActionCable live features, and SQLite/PostgreSQL support.
